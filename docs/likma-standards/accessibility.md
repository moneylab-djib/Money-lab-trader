# Accessibility quality floor
Target WCAG 2.2 AA on web product flows; this is not a certification claim.
Use semantics, labels and native controls before custom ARIA.
Check keyboard use, visible focus, focus order and return from modals.
Text contrast: 4.5:1 normal, 3:1 large; relevant non-text UI contrast 3:1.
Pointer targets: 24×24 CSS pixels or a documented WCAG exception. Prefer larger targets for touch.
44×44 is an enhanced AAA criterion, not the AA minimum.
Check reflow/zoom, errors, long translations, screen reader labels and reduced motion.
Automated scanning complements manual checks; a clean scan does not establish conformance.
