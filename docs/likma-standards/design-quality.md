# Design quality standard

## Required

- The interface has a recognisable relationship to the product.
- Art direction is documented before a large UI implementation.
- Typography, colour, spacing, states and interaction behaviour are intentional.
- Loading, empty, error, success and disabled states are designed.
- Responsive behaviour is defined for the real target devices.
- Text is understandable without relying on placeholder copy.
- Accessibility is treated as part of the design, not a late patch.

## Anti-patterns

- Generic dashboard structure without product justification.
- Cards used as the default container for every section.
- Decorative gradients or glass effects used to create fake personality.
- One visual treatment reused across unrelated products.
- A screenshot presented as finished without checking real content and states.

## Subject-swap test

Replace the product name and content with an unrelated product. If the design still feels unchanged, the design is probably too generic and needs stronger product-specific direction.
